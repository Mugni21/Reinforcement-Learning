# Data

This folder is intentionally empty in the repository. Image datasets are not tracked by git.

## Download the Dataset

📁 **[SuperMarioBros Dataset — Google Drive](https://drive.google.com/drive/folders/1aeO00PO_waH5QI8PLEW2JH2kz-OMDwQD?usp=sharing)**

## After Downloading

Place the folders here so the structure looks like this:

data/
├── TrainImages/
│   ├── TrainLvl1/      ← training screenshots of Level 1
│   └── TrainLvl8/      ← training screenshots of Level 8
├── ValidationImages/
│   ├── ValidationLvl1/
│   └── ValidationLvl8/
└── TestImages/
├── TestLvl1/
└── TestLvl8/

The notebook will automatically find the data here — no path changes needed.
